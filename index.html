KMS: Public projects repositories

Projects are primarily maintained offline in private repos, but they are mirrored to following public servers for 1) backup purposes and 2) to allow commits from more developers active on most public Git servers.

If you want to contribute, you can use any of below servers (I'll synchoronize to others myself), but I recommend to contact me first to discuss potential changes to avoid disappointment from rejected commits (I have some no-go rules, for example regarding compatibility, reproducibility, full offline-development or privacy matters). So typical reason for rejecting commits is eg. because change doesn't work for Windows 2000 or DOS, if product is ported to these obsolete OS.

Please note that due to various reasons I could lost access to some server in future (for example when provider requests some private information to login) so it could happen that you see just abandoned obsolete contents. I recommend to check below links to verify whether you couldn't use/contribute more recent version.

  • GitHub: https://github.com/Kopromaster
  • GitLab: https://gitlab.com/kms9900302
  • Codeberg: https://codeberg.org/kopromaster
  • BitBucket: https://bitbucket.org/kopromaster/workspace/overview/ (needs login first)
